# Hotel Management Dashboard 📊

This project delivers a comprehensive **Hotel Management Dashboard** using **Power BI**, **SQL**, and **Excel**. It aims to provide insights into booking trends, customer behavior, room occupancy, and financial performance to assist hotel managers in making informed decisions.

## 📁 Project Files

- `Hotel_mgmt.sql`: SQL script for creating and populating the hotel management database.
- `hotel_revenue_historical_full.xlsx`: Excel dataset containing historical hotel revenue and operational data.
- `PowerBi_Dashboard.pbix` : Power BI dashboard file visualizing the data with interactive visuals and insights.

## 💡 Features

- Dynamic overview of bookings, revenues, and cancellations
- Visual breakdowns of customer segments and room categories
- Room occupancy and availability tracking
- Financial trends including revenue, profit, and loss
- Interactive filtering by date, room type, region, etc.

## 🛠️ Tools Used

- **Power BI**: For data modeling and dashboard creation
- **SQL**: For data preparation and management
- **Excel**: As a source file containing raw hotel data

## 🚀 How to Run

1. Open `hotel_revenue_historical_full.xlsx` to review the raw dataset.
2. Optionally import and execute `Hotel_mgmt.sql` in your local database (SQL Server, MySQL, etc.).
3. Open `PowerBi_Dashboard.pbix` in Power BI Desktop.
4. If needed, update the data source paths to match your local file/database locations.
5. Refresh the Power BI dataset to load the latest data.
